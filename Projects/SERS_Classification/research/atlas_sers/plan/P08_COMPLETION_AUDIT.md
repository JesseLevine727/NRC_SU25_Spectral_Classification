## 2. Resolved owner choices and remaining specifications

The owner approved the recommended choices on 2026-10-04. This checkpoint records their scope without treating them as resource or execution permission.

1. **Normalization selector, P08-A06:** freeze each context's MIN-selected family and retune only its hyperparameters. The unselected full-selector and approved fixed-family four-control ceilings are **525,288** versus **42,368 model fits**, with **1,040 scalar temperatures** in either case. These answer different questions; N2 is now explicitly approved as the narrower conditional sensitivity, not as a universal optimum search.
2. **Regenerated populations, P08-A07:** repeat registered source-only model selection in the notes-clear and Mira-1-excluded tiers before freezing neural identities across preprocessing. New physical-master roles and support must be enumerated rather than copying the primary contexts.
3. **Perturbation placement, P08-A08:** alter the shared interpolated spectrum before the numerical preprocessing pipeline. Altering the final model input would test a different failure mechanism and is not selected.
4. **Synthetic shift edges, P08-A09:** use constant endpoint extension for unsupported coordinates in the ±5 cm⁻¹ shift. Unmeasured edge values cannot be presented as observed Raman signal.

The subsequent [perturbation design](P08_PERTURBATION_PROTOCOL.md) and [inference specification](P08_PERTURBATION_INFERENCE.md) now declare discrete severity levels, impulse magnitudes, random replicates, source-noise estimation, zero-dose parity and statistical contrast families.
