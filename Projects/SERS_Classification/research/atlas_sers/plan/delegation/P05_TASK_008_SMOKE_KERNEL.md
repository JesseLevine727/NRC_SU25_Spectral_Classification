## API and boundaries

`train_smoke_fit(*, values, observations, noise_metadata, role_id, recipe, seed, device, epochs=8, batches_per_epoch=4, maximum_fit_seconds=120, global_deadline=None, maximum_cuda_allocated_bytes=4294967296, on_epoch=None)` returns a `SmokeFitResult` dataclass. `values` is a source-fitting-only NumPy float32 matrix(N,1401), finite, row-minmax[0,1]. `observations` is the matching list of Observation records. `noise_metadata` is a pandas frame with observation_uid, first_difference_noise_mad, intensity_range in matching order. Strictly validate unique/ordered identities, one station, exactly3 chemicals, finite nonnegative noise and positive raw ranges. Never accept validation/test arrays. Epoch/batch arguments may be reduced (1..8 /1..4) for synthetic unit tests; production orchestration will require the full contract-pinned8×4 schedule. No argument may expand it.

Recipe must exactly match one of D0-M,D1,D2,D3 and its fixed lambda/head specification. Optimizer is fixed AdamW(lr0.0003,weight_decay0.0001), no scheduler/early stopping/calibration, clipping5. Model is AcquisitionClassifier; enforce exact208691/212851 parameters and no BatchNorm. Reuse P04 `_noise_quantiles`, `_augment`, `_state_hash`, `_seed_from`, `_metric_values` without changing P04. Scope is input/output-in-memory only; callback allows the later supervisor-controlled writer to retain partial histories.

`SmokeFitResult` must include: status/reason, list-of-dict history, parameter count, initial/final full-model state digests, initial/final backbone digests, initial/final head digests orNone, terminal CPU-cloned state_dict, augmentation/sampling/pair digests, exact completed optimizer steps, elapsed seconds, peak CUDA bytes and finite/nonzero gradient/support summaries. Failures return a terminal reason and all completed history, not a blank replacement. Use sanitized reason codes rather than raw exception text/paths/identifiers. No retry inside the function.

## Determinism and loop

Use common role+seed-derived initialization across recipes. Create the backbone before the optional head. Reset the training/dropout RNG AFTER optional head construction, and reset per batch from role+seed+epoch+ordinal (never recipe or execution ID). Batch sampling uses the frozen sampler. Augmentation uses unchanged P04 helper, source-fit noise quantiles and a separate common role+seed+epoch+ordinal NumPy RNG; preserve replay digest/draw counts. Call model.train each update. CE always uses equal-master sampler weights. Compute auxiliary losses only as enabled, but retain honest applicable/available/support counters. Missing terms are differentiable zeros without lambda redistribution. This must yield EXACT sparse D0-M/D2 and D1/D3 checkpoint/CE/total-loss equality under common RNGs.

Before each backward, reject nonfinite components/total loss. After backward, check all present gradients finite, record backbone/head gradient norms and nonzero counts before clipping, clip norm5, step. Check deadlines before/after batches and check allocated/peak CUDA memory. CUDA work must be synchronized for timing/finite checks; no CPU fallback after starting a CUDA fit. At most32 updates for a production fit. Failures preserve previous finite history/state where possible.

At epoch end, evaluate only original fitting rows in model.eval/no_grad, collecting logits/embeddings in bounded chunks. Record train-only spectrum BA/NLL/predicted-class-count, mean embedding variance/norm; these never select a checkpoint. Save terminal state, not best training accuracy. Callback receives a copy of the epoch record.

History rows include epoch,chemical_ce,total_loss,supcon_loss,paired_loss,supcon_enabled,paired_enabled,supcon_available_batches,paired_available_batches,eligible_anchor_count,zero_positive_anchor_count,paired_master_count,gradient_norm_mean,gradient_norm_max,head_gradient_norm_mean,backbone_gradient_norm_mean,clipped_fraction,embedding_variance,embedding_norm_mean,train_ba,train_nll,train_predicted_class_count,optimizer_steps. Define support counts clearly as totals across that epoch's draws (not independent samples). Inapplicable losses may have numeric zero but are always accompanied by enabled/availability fields. Do not put observation/master IDs in history.

Sampling/augmentation/pair semantic digests must exclude wall-clock/memory values and recipe ID so matched procedures can be checked. Pair digests describe sorted eligible positive UID pairs for each sampled batch with role/epoch/ordinal provenance, not an aggregate master pair mislabeled as one observation. Replaying a numerical specification must reproduce histories (apart from cost fields) and state digests exactly. Output metrics cannot set future hyperparameters.
