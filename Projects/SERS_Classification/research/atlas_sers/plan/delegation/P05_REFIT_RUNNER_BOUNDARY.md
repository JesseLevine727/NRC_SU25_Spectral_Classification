# P05 refit-runner implementation boundary

This assignment implements the already approved comprehensive permit. It does not authorize a new scientific run or a retry. The supervisor must accept the implementation and its tests before execution from a fixed checkout.

## Required entry point and prerequisite

Implement `p05_comprehensive_refits.run_refits(*, project_root, artifact_root, contract_path, permit_path, device="cuda")`. No held-out prediction belongs here.

`inputs.prepare(project_root, artifact_root, contract_path, permit_path, require_unstarted=False)` returns authenticated paths, contract, permit, support, ledger and pilot bundle. `support` has `manifest`, `contexts`, and `roles` attributes containing sequences of row dictionaries.

The separately reviewed `p05_refit_authority.authenticate_selection(bundle, *, deadline)` returns a dictionary with keys `plan`, `prior_seconds`, `source_optimizer_steps`, `development_receipt`, and `selection_receipt`. It authenticates completed development and selection manifests, the pilot manifest, source bindings and every frozen plan specification. It performs no numerical training or calibration. The runner must charge this authentication against the remaining cumulative time. Read the selection receipt's finite cumulative time before its expensive scans; the authority subsequently verifies that bound against development. There is no clock reset. All stage and kernel clocks use `time.perf_counter()`, never `time.time()`.

## Existing APIs (do not invent replacements)

- `core._configure_environment()` sets deterministic process environment. Import the refit and calibration modules and set `torch.set_num_threads(1)` before capturing provenance; this initializes the numerical libraries before the environment fingerprint.
- `core._capture_provenance(repository_root, project_root, artifact_root)` and `pilot._post_run_reauth(artifact_root, contract, support, provenance_before, repository_root, project_root)` protect inputs and implementation state. `_post_run_reauth` returns after-provenance.
- `pilot._checkpoint_preflight(torch, artifact_root)`, `_free_cuda_bytes(torch)`, `_enforce_cuda_cap(torch, device)` provide existing device checks. Constants are `MINIMUM_FREE_CUDA_BYTES` and `MAXIMUM_CUDA_ALLOCATED_BYTES`. Production accepts CUDA only; tests replace the device boundary, not the scientific kernel.
- `refit_io.prepare_refit_inputs(bundle, spec)` returns **all** kernel input keywords, including `role_id`, `recipe`, `seed`, and `epochs`. Do not pass those twice.
- `refit.train_refit(**prepared, device=device, maximum_fit_seconds=120.0, global_deadline=deadline, maximum_cuda_allocated_bytes=4294967296, on_epoch=recorder)` returns a dataclass, including partial failure evidence.
- `refit_io.persist_refit_result(torch, unit_dir, spec, result)` requires an already existing exclusive directory, writes `summary.json` and any `terminal.pt`, and rejects overwrites. `refit_io.check_completed_refit(torch, unit_dir, spec, result)` verifies completion and checkpoint/summary integrity.
- `pilot.open_history_recorder(unit_dir, refit_id)` records at `histories/<refit_id>.jsonl`. Here `development` means **`p05_comprehensive_development`**, not the numerical `p05_development` module. `development._GuardedRecorder(recorder, budget, deadline)` wraps it; `development._lower_bound_updates(unit_dir, refit_id)` counts completed durable epochs times four if a kernel raises without returning a result. Always close the recorder in `finally`. Mark such counts inexact. A returned result's optimizer steps must be charged **before** persistence or acceptance checks.
- `calibration.calibrate_spec(spec=spec, ledger=ledger, manifest=manifest, load_logits=load_logits)` is **keyword-only** and returns `(TemperatureCalibration, audit)`. The loader receives a full slot dictionary. Resolve its unit by `unit_id`; reused pilot slot IDs come from `inputs.pilot_slot_ids(bundle)`. Use `inputs._pilot_run_dir(artifact_root)` for those and the comprehensive `develop/units/<unit_id>` directory for other slots. Then load `executions/<pilot.execution_id(unit, slot)>/validation_logits.npz` via `inputs._load_logits(numpy, path)`.
- Persist calibration as `dataclasses.asdict(calibration)` and the audit separately; reload with `TemperatureCalibration(**payload)` after converting `class_vocabulary` to a tuple. Require `state_sha256` equality and exact classes. No held labels/logits may enter calibration.
- `StorageBudget` scans both governed private namespaces once, tracks a small number of growing stage files and one active unit. `activate_unit(path)` creates that exclusive directory. Files inside it are counted by the active-unit scan; **never** also call `account_new_file` for those. Outside units, register growing files before creation or charge each static file once. `close_unit()` seals/account its files. `reconcile()` is allowed only without an active unit.
- `core._atomic_write(path, canonical_json_bytes(payload))`, `core._mkdir_exclusive(path, reason)`, `core._write_manifest(stage)` and `pilot._verify_manifest(stage)` are the existing persistence primitives. `freeze._budgeted_write` can be reused for static files outside active units. `development._append_jsonl` durably appends events.

## Exact lifecycle

1. Validate CUDA, authenticate bundle, derive run root `artifact/p05comprehensive/runs/<permit>`, read the finite prior cumulative bound and set `deadline = wall_start + 172800 - prior`. Authenticate completed selection with that deadline. Reject pre-existing `refits` or `refit_receipt.json`; consume an exclusive stage once. Authentication-only failure must not start a fit.
2. Capture provenance and persist it. Register stage events/progress before creation. Sort unique refits by `(context_id, seed, recipe_id, refit_id)`. Aliases do not consume training or calibration counts.
3. Activate `refits/units/<refit_id>` and persist its binding/lease before any numerical operation. Prepare only source rows. Charge scalar-started before calibration; persist/reload calibration and audit. Charge neural-started immediately before the neural call. Count calibration failure separately from an unstarted neural fit.
4. Call the fixed-epoch kernel once. Preserve any partial result, exact returned step count and failed state. On success validate saved summary and terminal checkpoint, close the unit manifest and storage accounting, then advance durable progress. No automatic retries.
5. Preserve slim history/digest/support metadata for each context/seed until its 2 or 3 unique recipes are available. Require identical initial backbone and per-epoch sampling/augmentation/pair digest prefixes across those recipes. **Do not use the pilot helper requiring all four recipes.** On source roles lacking cross-instrument master pairs, require zero pair support for D2/D3; if both D0-M/D2 or D1/D3 are actually present and have the same inherited epoch count, require initial/terminal state and numeric-history equality. Different epoch counts do not justify a terminal-state equality check. Do not run extra fits to obtain missing pairs.
6. At completion require exact unique coverage, both numerical started/completed counts equal the unique-spec count, zero failures, exact updates and all 2,880 aliases resolved. Reauthenticate inputs/provenance; write summary and full stage manifest. Verify manifest, reconcile storage, and only then capture elapsed time for run-root `refit_receipt.json`. Receipt binds permit/core/ledger, selection plan ID, stage-manifest SHA, counters and cumulative scientific time. Stage summary may have an earlier elapsed timestamp; the receipt is authoritative.
7. On any consumed-stage failure, preserve a failure summary/manifest and honest counters, including inexact partial-step lower bounds if necessary. Never create a success receipt. Raise a stable path-free error. Preserve interrupts.

## Bounds and claims

No more than 2,880 unique refits or 2,880 scalar calibrations. No more than 800 optimizer updates per refit or 14,227,200 cumulative **new** updates including source development. The source fit ceiling is 14,904, separate from 36 reused pilot fits. Total time is 172,800 seconds including inherited time; storage is 107,374,182,400 bytes, allocated CUDA is 4,294,967,296 bytes, and each refit is limited to 120 seconds. Require at least 5,368,709,120 free CUDA bytes before launch. This stage produces no held predictions, benchmark metrics or claim of superiority.
