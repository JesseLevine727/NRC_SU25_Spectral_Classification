# Standard Raman Classification

This directory groups the standard Raman single-spectrum classification work.

## Main areas

- [Scripts](/home/elfo/Documents/NRC/NRC_SU25_Spectral_Classification/Projects/Standard_Raman_Classification/Scripts)

- [Notebooks](/home/elfo/Documents/NRC/NRC_SU25_Spectral_Classification/Projects/Standard_Raman_Classification/Notebooks)

- [ExtendingSiamese](/home/elfo/Documents/NRC/NRC_SU25_Spectral_Classification/Projects/Standard_Raman_Classification/ExtendingSiamese)
