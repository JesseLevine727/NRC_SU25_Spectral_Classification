# Standard Raman Classification

This directory groups the standard Raman single-spectrum classification work.

## Main areas

- [Scripts](Scripts)
  Core Python implementations such as `CaPSim.py`, `CaPSim_kNN.py`, `PCA_Classification.py`, and `SiameseNetwork.py`.

- [Notebooks](Notebooks)
  Exploratory notebooks for CaPSim, PCA, Siamese one-shot learning, and dataset creation.

- [ExtendingSiamese](ExtendingSiamese)
  Extended Siamese experiments with their own `data`, `models`, `results`, `scripts`, and slides.
